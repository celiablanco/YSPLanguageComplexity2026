# YSPLanguageComplexity2026
Repo for code and data for YSP26 Language Complexity project

The project title is "Comparative Exploration of Language Efficiency", it has the objective of exploring the efficiency of enconding of written languages. The ideia can be summarized by "The most efficient language will be the one that has the most amount of _____ per written text".
There is no unanimous definition of efficiency, therefore it will be taken several measurements to try and establish some pattern.
For starter the following measurements will be taken:
    1. File size
    2. Compressed File size
    3. Character complexity
To make fair comparisons the same text will be machine translated before taking the measurements as its acknowledged that the current machine translation makes good equivalent bodies of text (The text would be grammatically correct in both languages and have the same meaning).

The number of languages will be limited by available tools, for example, in the packaged used, Google Translate doesn't have a Portuguese (Portugal) and Portuguese (Brazil).

How the measurements will be used to calculate efficiency has not been decided.

    translate.py will translate all files in the paste 'source' into every language in 'target_language' and put it on the 'translated' paste and named '[filename]_[language].txt'.
    To use: first install the package with the command
$ pip install deep-translator
    Then, run the command
$ python translate.py

    It uses Google Translator.
    It has not been tested with file types other than .txt.
    The file is separated into 4500 char chunks and reassembled, because of the google_translator limit.
    All available languages on Google translate are copied below.
    The test was made using as source the whole text of 'The Art of War' from https://classics.mit.edu/Tzu/artwar.html in English And the Japanese text of Art of War (孫子の兵法) from https://sonshi-heihou.com/%e5%ad%ab%e5%ad%90%e8%a8%88%e7%af%87-%e6%9b%b8%e3%81%8d%e4%b8%8b%e3%81%97/ into every available language.
