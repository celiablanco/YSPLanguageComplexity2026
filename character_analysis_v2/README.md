# Character Analysis V2

## Overview
This version extends the previous language analysis by computing character-level statistics across all translated languages.
Added full-book character-level analysis.

## Metrics Computed
- Total characters
- Characters excluding spaces
- Unique characters
- Word count
- Sentence count
- Average characters per word
- Average words per sentence
- Average characters per sentence

## Output Files
- character_statistics.csv
- unique_characters.png
- avg_characters_per_word.png

## Observations
- Languages written in logographic scripts (such as Chinese) use a much larger set of unique characters.
- Alphabetic languages generally reuse a relatively small character inventory.
- Average word length differs significantly between writing systems, highlighting structural differences across languages.
